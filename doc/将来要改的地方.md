    测试在 BeforeEach 建立「一被调用即失败」的 Mock 基线

    仅当字符串参与路径构造、文件名或命令参数拼接时才需显式拒绝纯空白与首尾空白；
    用命令式 if + throw 强类型异常（项目既有惯例），不用 ValidateScript（泄露源码）；不做静默 Trim
  - 冲突：规则文档第 44-46 行当前描述「在 catch 中捕获 Error 级中断后重抛类型化异常」的另一套方案，

  - 普查：grep 全部 [string] 参数与类属性，判断是否进入路径构造；候选用 \\?\ 前缀真实验证
    （普通 provider 路径会掩盖尾空格目录）；产出缺口清单并标注理由
